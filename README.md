# Estimación indirecta de riesgo relativo asociado a mercurio mediante Machine Learning, Sentinel-2, proxies ópticos y variables de presión minera: prueba de concepto en la Laguna Gredal, Taraira (Vaupés)

Este sera el repositorio del trabajo, se usara una plantilla que comparte el "Programa de Formación en Machine Learning y Data Science" de la Universidad Nacional de Colombia, pára desarrollar proyectos de ciencia de datos e inteligencia artificial de manera ordenada y en equipo.

La plantilla se basa en la metodologia Team Science Precess (TDSP), la cual tiene fases similares a la metodologia CRISP-DM, la cual es la metodologia que guia la prueba de concepto.

Esta plantilla proporciona las siguientes carpetas y archivos:

* `src`: Aqui reposa el código del proyecto.
* `docs`: En esta carpeta se encuentran las plantillas de los documentos necesarios para guiar el trabajo segun la metodología.
* `scripts`: esta carpeta contiene los scripts o notebooks que se ejecutarán.
* `pyproject.toml`: Este sera un archivo en el cual se hace la definición del proyecto en Python.
